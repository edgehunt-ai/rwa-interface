# rwa_api_client (EXPERIMENTAL)
RWA Trading Platform 的公共产品契约，是客户端和服务端共享的唯一 wire contract。
它覆盖正式客户端所需的认证、市场、交易、资金、组合与实时事件能力；健康探针、
管理写接口和 provider 私有字段不属于本契约。

* **认证与交易钱包** — 登录由 Privy SDK 完成。客户端把 Privy access token
  直接作为 Bearer credential；本 API 不接收 body token，也不签发第二套 access token。
* **行情** — 股票分组、榜单、K 线、美股参考价与交易时段可匿名读取；
  客户端一旦提供 Bearer credential，服务端仍会验证它。自选列表和收藏写操作需要登录。
* **交易** — bStocks 现货与 HIP-3 永续的预览、订单、仓位和钱包动作。
* **资金** — 钱包、资金准备、入金、划转、Claim 与提现。
